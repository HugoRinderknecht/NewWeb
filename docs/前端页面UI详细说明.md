# Dreamcraft Astra 前端页面 UI 详细说明

> **文档性质**: 基于源码 `<template>` 部分的静态分析，描述每个页面的实际界面布局、交互元素、按钮文本、表格列、表单字段和视觉样式。
> **分析日期**: 2026-06-04

---

## 全局 UI 设计规范

### 组件体系

| 组件 | 用途 |
|------|------|
| `ArtTable` | Element Plus 表格封装，内置分页 |
| `ArtTableHeader` | 表格上方工具栏（列切换、刷新、搜索栏开关） |
| `ArtSearchBar` | 可复用搜索表单组件 |
| `ArtSvgIcon` | 图标组件，使用 Remix Icon（`ri:*`） |
| `ArtButtonTable` | 表格操作列紧凑图标按钮（编辑/删除/新增） |
| `ArtButtonMore` | 下拉"更多操作"按钮 |
| `ArtCountTo` | 数字动画计数器 |
| `ArtBarChart` / `ArtLineChart` / `ArtRingChart` / `ArtRadarChart` | ECharts 图表封装 |
| `ArtVideoPlayer` | 视频播放器组件 |
| `ArtStoryboardPanel` | 分镜可视化面板（网格+时间线双视图） |
| `ProjectSwitcher` | 项目切换下拉组件 |

### 状态标签颜色约定

| 颜色 | Element Plus type | 含义 |
|------|------------------|------|
| 🟢 绿色 | `success` | 已启用、在线、已通过、已完成 |
| 🟡 橙色 | `warning` | 已禁用、离线、待审核、处理中 |
| 🔴 红色 | `danger` | 已删除、已驳回、已取消、失败 |
| ⚪ 灰色 | `info` | 未知、默认、已归档 |
| 🔵 蓝色 | `primary` | 登录、菜单类型、进行中 |

### 通用页面模式

- **页面容器**: `art-full-height` 类，通常配合 `v-loading` 指令
- **卡片容器**: `art-table-card h-full` 类
- **头部工具栏**: `flex-cb`（flexbox space-between），左侧标题，右侧操作按钮
- **搜索模式**: 所有列表页有 `ri:search-line` 前缀图标的可清除搜索输入框
- **分页模式**: `total, sizes, prev, pager, next, jumper` 布局，background 样式
- **对话框模式**: `ElDialog` + footer 模板含"取消"+ 主操作按钮，使用 `destroy-on-close`
- **所有文本标签均为中文**

## 1. 系统管理 (`/system`)

### 1.1 管理员仪表盘 (`/system/admin-dashboard`)

**布局**: 纵向两行

**第一行 — 统计卡片（4列等宽）**:
| 卡片 | 图标 | 背景色 | 数据 |
|------|------|--------|------|
| 总用户数 | `ri:user-line` | bg-primary（蓝） | `totalUsers` |
| 总团队数 | `ri:team-line` | bg-success（绿） | `activeUsers` |
| 总项目数 | `ri:folder-line` | bg-warning（橙） | `totalProjects` |
| 今日AI调用 | `ri:flash-line` | bg-danger（红） | `dailyVisits` |

每张卡片：左侧 48×48 圆角色块+白色图标，右侧标签文本+2xl粗体数值。

**第二行 — 图表卡片（2×2 网格）**:
| 卡片标题 | 状态 |
|---------|------|
| 用户增长趋势 | 占位符 `[ECharts ...]` |
| 团队活跃度 | 占位符 |
| 存储使用统计 | 占位符 |
| AI服务调用分布 | 占位符 |

### 1.2 用户管理 (`/system/user`)

**搜索栏（`UserSearch`）**: 5个字段 — 用户名(输入)、手机号(输入,maxlength 11)、邮箱(输入)、状态(下拉:在线/离线/异常/注销)、性别(单选:男/女)

**工具栏左侧**: "新增用户"按钮（v-ripple）

**表格列**:
| 列 | 宽度 | 渲染方式 |
|----|------|---------|
| 选择框 | 55 | checkbox |
| 序号 | 60 | 索引 |
| 用户名 | 280 | 头像(ElImage,可预览) + 用户名 + 邮箱(小字) |
| 性别 | - | 可排序 |
| 手机号 | - | 文本 |
| 状态 | - | ElTag: 1=在线(success) 2=离线(info) 3=异常(warning) 4=注销(danger) |
| 创建日期 | - | 可排序 |
| 操作 | 120 | 编辑(edit) + 删除(delete)，fixed right |

**新增/编辑对话框（30%宽度）**: 用户名(必填,2-20字符)、手机号(必填,手机格式)、性别(下拉:男/女)、角色(多选,来自roleList)

**删除确认**: "确定要注销该用户吗？"（title: "注销用户"）

### 1.3 角色管理 (`/system/role`)

**搜索栏（`RoleSearch`）**: 角色名称、角色编码、角色描述、角色状态(启用/禁用)、创建日期(日期范围,快捷键:今日/最近一周/最近一个月)

**工具栏**: "新增角色"按钮 + 搜索栏开关

**表格列**:
| 列 | 宽度 | 渲染方式 |
|----|------|---------|
| 角色ID | 100 | 文本 |
| 角色名称 | min 120 | 文本 |
| 角色编码 | min 120 | 文本 |
| 角色描述 | min 150 | 溢出tooltip |
| 角色状态 | 100 | ElTag: true=启用(success) false=禁用(warning) |
| 创建日期 | 180 | 可排序 |
| 操作 | 80 | ArtButtonMore下拉: 菜单权限(ri:user-3-line)、编辑角色(ri:edit-2-line)、删除角色(ri:delete-bin-4-line,红色) |

**菜单权限对话框（520px）**: ElTree 树形复选框展示完整菜单树，auth按钮作为叶节点。底部按钮：获取选中数据、全部收起/展开、取消全选/全部选择、保存。

**编辑角色对话框（30%宽度）**: 角色名称(必填)、角色编码(必填)、描述(必填,textarea 3行)、启用(ElSwitch)

### 1.4 菜单管理 (`/system/menu`)

**搜索栏**: 菜单名称(输入)、路由地址(输入)

**工具栏**: "添加菜单"按钮（v-auth="'add'"）+ 收起/展开切换

**表格（树形结构，无斑马纹）**:
| 列 | 渲染方式 |
|----|---------|
| 菜单名称 | `formatMenuTitle` 格式化 |
| 菜单类型 | ElTag: 按钮(danger) / 目录(info) / 内嵌(success) / 菜单(primary) / 外链(warning) |
| 路由 | `meta.link` 或 `path`，按钮为空 |
| 权限标识 | 按钮显示 `authMark`；菜单显示"3 个权限标识" |
| 编辑时间 | 硬编码 "2022-3-12 12:00:00" |
| 状态 | 固定 ElTag success "启用" |
| 操作 | 按钮行:编辑+删除；菜单行:新增权限+编辑+删除 |

**菜单对话框（860px）**: 菜单/按钮单选切换。菜单模式18个字段（名称、路由、权限标识、组件路径、图标、角色权限、排序、外链、徽章、激活路径 + 8个Switch开关）。按钮模式3个字段（名称、标识、排序）。

### 1.5 审计日志 (`/system/audit-logs`)

**头部**: 标题"审计日志" + 右侧筛选（操作人输入、操作类型下拉:登录/新增/修改/删除/导出、日期范围、查询/重置/导出按钮）

**表格列**: 日志ID、操作人、操作类型(ElTag:登录primary/新增success/修改warning/删除danger/导出info)、操作对象、IP地址、操作时间、结果(成功success/失败danger)、操作(详情)

**详情对话框（600px）**: ElDescriptions(1列,border) 8个字段 + JSON详细内容(`<pre>` 灰色背景块)

### 1.6 计费配置 (`/system/billing-config`)

**头部**: 标题"计费配置" + "添加定价"按钮

**表格列**: 模型名称、模型编码、积分单价(text-theme themed色)、计费单位、状态(ElSwitch)、更新时间、操作(编辑+删除)

**对话框（600px）**: 模型名称(必填)、模型编码(必填)、积分单价(ElInputNumber,min 0,精度2)、计费单位(下拉:次/千字符/秒/张)

### 1.7 平台团队管理 (`/system/platform-teams`)

**头部**: 标题"平台团队管理" + 筛选（团队名称/ID输入、状态下拉:启用/禁用、查询+创建团队按钮）

**表格列**: 团队ID、团队名称、负责人、成员数、项目数、状态(ElSwitch)、创建时间、操作(查看成员+删除)

**成员对话框（700px）**: 表格 — 用户ID、用户名、角色(ElTag)、加入时间

### 1.8 视频模型配置 (`/system/video-models`)

**头部**: 标题"视频模型配置" + "添加模型"按钮

**表格列**: 模型名称、模型编码、提供商、最大时长(秒)、支持比例(多个ElTag:16:9/9:16/1:1/4:3)、状态(ElSwitch)、操作(编辑+删除)

**对话框（600px）**: 模型名称(必填)、模型编码(必填)、提供商(必填)、最大时长(ElInputNumber,min 1)、支持比例(多选)

### 1.9 Dify工作流配置 (`/system/dify-workflows`)

**头部**: 标题"Dify工作流配置" + "添加配置"按钮

**表格列**: 工作流编码、工作流名称、API端点、API Key(脱敏:前4+****+后4,灰色)、超时(秒)、状态(ElSwitch)、操作(编辑+测试连接+删除)

**对话框（600px）**: 工作流编码(必填,编辑时禁用)、工作流名称(必填)、API端点(必填)、API Key(密码输入,显示切换)、超时时间(ElInputNumber,1-300)

### 1.10 运行时配置 (`/system/runtime-config`)

**头部**: 标题"运行时配置" + "刷新缓存"按钮 + "添加配置"按钮

**表格列**: 配置键、配置值(敏感值脱敏:****+后4,灰色)、描述、更新时间、操作(编辑+删除)

**对话框（600px）**: 配置键(必填,编辑时禁用)、配置值(必填,textarea 3行)、描述、敏感配置(ElSwitch)

### 1.11 个人中心 (`/system/user-center`)

**双栏布局**: 左侧个人信息卡(112宽) + 右侧内容区

**左侧卡片**: 封面图(bg.webp) + 头像(80×80圆形) + 用户名 + 副标题 + 邮箱/职位/地区/部门 + 标签chips

**右侧 — 基本设置**: 姓名+性别(行1)、昵称+邮箱(行2)、手机+地址(行3)、个人介绍(textarea)。全部禁用直到编辑模式。底部"编辑"/"保存"切换按钮。

**右侧 — 更改密码**: 当前密码、新密码、确认新密码。全部禁用直到编辑模式。
