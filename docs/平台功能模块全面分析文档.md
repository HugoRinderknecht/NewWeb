## 1. 系统管理

**路由前缀**: `/system`  
**访问角色**: platform_admin（全功能）、team_admin（仅用户管理）

### 1.1 功能清单

| 子功能 | 路由 | 说明 |
|--------|------|------|
| 管理员仪表盘 | `/system/admin-dashboard` | 平台级统计概览 |
| 用户管理 | `/system/user` | 用户CRUD、状态管理 |
| 角色管理 | `/system/role` | 角色CRUD、菜单权限分配 |
| 菜单管理 | `/system/menu` | 树形菜单路由管理、按钮级权限 |
| 审计日志 | `/system/audit-logs` | 配置变更日志查看 |
| 计费配置 | `/system/billing-config` | AI模型定价配置 |
| 平台团队管理 | `/system/platform-teams` | 平台级团队生命周期管理 |
| 视频模型配置 | `/system/video-models` | AI视频生成模型配置 |
| Dify工作流配置 | `/system/dify-workflows` | AI工作流集成配置 |
| 运行时配置 | `/system/runtime-config` | 系统键值对配置管理 |
| 个人中心 | `/system/user-center` | 个人资料编辑 |

### 1.2 核心功能详情

#### 管理员仪表盘
- **统计卡片**: 总用户数、总团队数、总项目数、今日AI调用（4色图标卡片）
- **图表区域**: 用户增长趋势、团队活跃度、存储使用统计、AI服务调用分布（ECharts占位）
- **数据来源**: `fetchGetDashboard()` API

#### 用户管理
- **搜索维度**: 用户名、手机号、邮箱、状态、性别
- **表格字段**: 用户头像+姓名+邮箱（组合渲染）、性别、手机号、状态标签、创建日期
- **状态模型**: 在线(success)、离线(info)、异常(warning)、注销(danger)
- **操作**: 新增用户、编辑用户、注销用户（设置status=4）
- **弹窗表单**: 用户名(2-20字符)、手机号(格式校验)、性别、角色(多选)

#### 角色管理
- **搜索维度**: 角色名称、编码、描述、状态、创建日期范围
- **表格字段**: 角色ID、名称、编码、描述、状态、创建日期
- **操作**: 新增角色、编辑角色、删除角色、菜单权限分配
- **权限分配**: ElTree树形复选框展示完整菜单树，支持全部展开/收起、全选/取消

#### 菜单管理
- **树形结构**: 支持目录、菜单、外链、内嵌、按钮5种类型
- **类型标签**: 按钮(danger)、目录(info)、内嵌(success)、菜单(primary)、外链(warning)
- **搜索**: 菜单名称、路由地址（客户端过滤）
- **操作**: 添加菜单、新增权限、编辑、删除
- **权限标识**: authList条目转为子节点展示

#### 审计日志
- **筛选**: 操作人、操作类型（登录/新增/修改/删除/导出）、日期范围
- **表格字段**: 日志ID、操作人、操作类型标签、操作对象、IP地址、操作时间、结果
- **详情弹窗**: ElDescriptions展示全部字段 + JSON格式详细内容

#### 计费配置
- **表格字段**: 模型名称、模型编码、积分单价（主题色高亮）、计费单位、状态开关
- **弹窗表单**: 模型名称、模型编码、积分单价(精度2)、计费单位（次/千字符/秒/张）

#### 平台团队管理
- **搜索**: 团队名称/ID、状态
- **表格字段**: 团队ID、团队名称、负责人、成员数、项目数、状态开关、创建时间
- **操作**: 创建团队（prompt输入）、查看成员、删除团队

#### 视频模型配置
- **表格字段**: 模型名称、模型编码、提供商、最大时长(秒)、支持比例（多标签）、状态开关
- **弹窗表单**: 模型名称、编码、提供商、最大时长、支持比例（多选）

#### Dify工作流配置
- **表格字段**: 工作流编码、名称、API端点、API Key（脱敏显示）、超时、状态开关
- **操作**: 编辑、测试连接、删除
- **API Key脱敏**: 前4位 + **** + 后4位

#### 运行时配置
- **敏感检测**: 配置键包含"key"/"secret"时自动标记为敏感
- **脱敏规则**: **** + 后4位
- **操作**: 添加配置、编辑、删除、刷新缓存

#### 个人中心
- **左侧栏**: 头像、封面、用户名、邮箱、职位、地区、部门、标签chips
- **右侧表单**: 姓名、性别、昵称、邮箱、手机、地址、个人介绍（编辑/保存切换）
- **密码更改**: 当前密码、新密码、确认密码

## 2. 仪表盘

**路由前缀**: `/dashboard`  
**访问角色**: platform_admin、team_admin、team_member、member

### 2.1 功能清单

| 子功能 | 路由 | 说明 |
|--------|------|------|
| 工作台 | `/dashboard/console` | 首页控制台，聚合展示核心指标 |
| 资源用量 | `/dashboard/usage` | 存储/AI积分/带宽使用统计 |
| 深度分析 | `/dashboard/analysis` | 项目产出、成员工作量、活动排名 |
| 报表生成 | `/dashboard/report` | 可配置报表生成与导出 |
| 数据看板 | `/dashboard/data-dashboard` | 综合数据看板（6+图表） |
| AI用量统计 | `/dashboard/ai-usage` | Token消耗、模型分布、项目分布 |
| 成本分析 | `/dashboard/cost` | 积分消耗趋势、功能分布、成本预测 |

### 2.2 核心功能详情

#### 工作台（控制台）
- **统计卡片（4列）**: 待处理审核、项目进度、负责项目数、积分余额（动画计数器 + 周同比变化）
- **图表区**: 用户概述（柱状图）、积分使用量（折线图）
- **列表区**: 最近项目（表格+进度条）、待处理审核（可滚动列表+状态筛选）、最新通知（已读/未读指示器）
- **新用户引导**: 三层判断逻辑 — 无用户名邮箱→完整引导 / 有信息无团队→仅邀请码 / 已完成→不显示

#### 数据看板
- **KPI卡片**: 核心指标 + 动画计数
- **6种图表**: 柱状图（项目产出）、折线图（趋势）、环形图（资源使用）、雷达图（团队能力）、热力图（活动）、散点图（产出效率）
- **数据获取**: Vue Query composables，自动缓存60秒

#### AI用量统计
- **统计卡片**: 总Token消耗、总请求次数、Input/Output Tokens（含周同比）
- **趋势图**: 按日/周/月切换的折线图
- **分布图**: 模型分布（环形）、项目分布（柱状）
- **明细表**: 搜索/模型筛选/导出 + 项目、模型、请求类型、Token数、费用

#### 成本分析
- **统计卡片**: 总积分消耗、总成本（元）、剩余余额、日均消耗
- **趋势图**: 积分消耗折线图
- **分布图**: 功能分布环形图（AI视频/语音合成/AI图片/剧本生成/分镜生成）
- **预测**: 基于历史平均的线性成本预测柱状图
- **明细表**: 搜索/筛选/分页

## 3. 项目管理

**路由前缀**: `/project`  
**访问角色**: platform_admin、team_admin、team_member、member

### 3.1 功能清单

| 子功能 | 路由 | 说明 |
|--------|------|------|
| 项目列表 | `/project/list` | 双视图（卡片/列表）、搜索、批量操作 |
| 项目编辑 | `/project/edit` | 7Tab详情页（概览/剧本/分镜/视频/资产/成员/设置） |
| 剧本管理 | `/project/scripts` | 项目级剧本CRUD（隐藏路由） |
| 角色管理 | `/project/characters` | 项目级角色CRUD（隐藏路由） |
| 剧集管理 | `/project/episodes` | 剧集+镜头管理，拖拽排序（隐藏路由） |
| 成员管理 | `/project/member` | 项目成员邀请、角色变更（隐藏路由） |
| 项目统计 | `/project/statistics` | 进度、资源消耗、分镜/视频统计 |

### 3.2 核心功能详情

#### 项目列表
- **双视图模式**: 卡片网格（封面+状态标签+成员数+操作按钮） / 表格列表（选择框+详情列）
- **搜索筛选**: 项目名称搜索、状态筛选（草稿/进行中/已完成/已归档）
- **排序**: 名称、创建时间（升降序切换）
- **批量操作**: 批量归档、批量恢复、批量删除
- **创建项目**: 项目名称(200字符)、项目描述(2000字符)、封面上传
- **状态模型**: 草稿(0/info)、进行中(1/primary)、已完成(2/success)、已归档(3/warning)

#### 项目编辑
- **概览Tab**: 左侧ProjectForm + 右侧统计（成员数、资产数、创建/更新时间、状态标签）
- **剧本Tab**: 剧本列表表格（标题、作者、版本、更新时间、操作）
- **分镜Tab**: 分镜列表表格（名称、场景、状态、更新时间、操作）
- **视频Tab**: 视频列表表格（名称、时长、分辨率、状态、更新时间、操作）
- **资产Tab**: 资产列表表格（名称、类型、大小、更新时间、操作）
- **成员Tab**: 嵌入ProjectMember子组件
- **设置Tab**: 基础配置 + 审核门禁（3个开关） + JSON配置编辑器 + 危险操作（归档/删除）

#### 剧集管理
- **双栏布局**: 左侧剧集列表（VueDraggable拖拽排序）+ 右侧镜头列表
- **镜头状态**: 待开始(info)、分镜中(warning)、首帧图(primary)、视频中(primary)、已完成(success)
- **操作**: 新建/编辑/删除镜头，多选（Ctrl+Click）批量删除，导航到分镜设计

#### 项目统计
- **统计卡片**: 总集数、总镜头数、项目成员、总时长
- **进度条**: 分镜完成率、首帧图完成率（派生指标）、视频完成率、整体完成率
- **资源消耗**: AI算力消耗、存储空间、Token消耗
- **分镜/视频统计表**: 状态、数量、占比（进度条）

### 3.3 数据流

```
项目列表 → (选择项目) → 项目编辑 → 各Tab页
    ↓                              ↓
项目Store ←── API查询层 ←── Vue Query hooks
    ↓
剧本/分镜/视频/资产/成员（各子模块）
```

**Store**: `useProjectStore`（当前项目ID、详情、配置）+ `useProjectDataStore`（剧集、分镜、角色、轨道）  
**API层**: `src/api/project.ts`（20+端点） + `src/api/queries/project.ts`（Vue Query封装）

## 4. 剧本管理

**路由前缀**: `/script`  
**访问角色**: platform_admin、team_admin、team_member、member

### 4.1 功能清单

| 子功能 | 路由 | 说明 |
|--------|------|------|
| 剧本库 | `/script/library` | 剧本CRUD、上传、审核提交/撤回 |
| 剧本编写 | `/script/write` | 全屏剧本编辑器，自动保存 |
| 剧本拆解 | `/script/decompose` | AI自动拆解为剧集 + 手动创建 |
| 人物小传 | `/script/profiles` | AI生成角色传记，3Tab详情 |
| AI审核结果 | `/script/ai-review` | 内容合规审查，违规项展示 |
| 创意资产 | `/script/version` | 角色/服装/场景/道具资产CRUD |

### 4.2 核心功能详情

#### 剧本库
- **项目切换栏**: ProjectSwitcher组件
- **统计卡片（4列）**: 剧本总数、草稿数、已完成数、审核中数
- **搜索筛选**: 剧本标题搜索、状态筛选（草稿/已完成）
- **表格字段**: 剧本标题、描述、状态标签、分集数、审核状态标签、创建时间
- **审核状态**: null=未提交(info)、1=待审核(warning)、2=已通过(success)、3=已驳回(danger)、4=已撤回(info)
- **操作**: 查看详情（含审核状态+内容预览）、编辑（跳转ScriptWrite）、提交审核、撤回审核、删除
- **上传剧本**: 支持.txt/.md格式，10MB限制，客户端解析
- **新建剧本**: 标题(必填)、描述、内容、状态选择

#### 剧本编写
- **侧边栏**: 剧本标题、描述、状态、创建者（只读）、创建时间（只读）、最后修改（只读）
- **编辑器**: 等宽字体textarea，字数/行数统计
- **自动保存**: 每30秒自动保存（有变更时）
- **保存状态标签**: 已保存(success)、保存中...(warning旋转)、未保存(info)
- **未保存守卫**: 离开页面时确认弹窗
- **引导弹窗**: 无scriptId时提示选择剧本或返回剧本库

#### 剧本拆解
- **双栏布局**: 左侧剧集列表（圆形序号徽章+名称+内容预览）+ 右侧详情编辑
- **AI拆解**: 调用`fetchDecomposeScript`，处理PROCESSING异步状态
- **手动创建**: 分集名称、排序号、分集内容

#### 人物小传
- **双栏布局**: 左侧人物列表（头像+名称+验证状态标签+身份）+ 右侧3Tab详情
- **Tab1 基本信息**: ElDescriptions — 姓名、身份、外貌特征、性格特点、语音参考、出场范围、验证状态
- **Tab2 背景故事**: 只读textarea
- **Tab3 关系网络**: 头像+名称+关系标签列表
- **AI生成**: 调用`fetchGenerateCharacterProfiles`，处理异步状态
- **验证状态**: 已验证(success)、待验证(warning)、未验证(info)

#### AI审核结果
- **状态视图**: 处理中（旋转加载+进度提示）/ 失败（错误结果+重新审核）/ 完成（统计+表格）/ 空（引导发起）
- **统计卡片（4列）**: 违规总数、高风险、中风险、低风险
- **全局警告**: ElAlert展示globalWarning
- **违规表格**: 位置、违规类型标签、风险等级标签、原文片段、命中词（红色粗体）、状态标签
- **违规类型**: 敏感信息(danger)、政治违规(danger)、色情低俗(danger)、暴力恐怖(warning)、版权风险(warning)、其他(info)
- **轮询机制**: 5秒间隔检查PROCESSING状态

#### 创意资产
- **Tab导航**: 全部、人物、服装、场景、道具、其他
- **搜索筛选**: 资产名称搜索、类型筛选
- **表格字段**: 资产名称（缩略图+粗体）、类型标签、描述、标签（最多3个+"+N"）、审核状态、来源、创建时间
- **类型标签**: 人物(primary)、服装(success)、场景(warning)、道具(danger)、其他(info)
- **操作**: 查看详情、编辑、上传参考图、删除
- **AI提取**: 从剧本自动提取资产
- **类型特化字段**: 人物（等级/别名）、道具（分类/归属人物）、服装（关联人物/场景）、场景（场景类型）

## 5. 分镜管理

**路由前缀**: `/storyboard`  
**访问角色**: platform_admin、team_admin、team_member、member

### 5.1 功能清单

| 子功能 | 路由 | 说明 |
|--------|------|------|
| 分镜设计 | `/storyboard/design` | 可视化面板、多模式生成、审核、版本历史 |
| 场景编排 | `/storyboard/scene` | 拖拽排序、批量编辑、相机参数 |
| 分镜预览 | `/storyboard/preview` | 网格/幻灯片/时间线3种视图模式 |
| 批量编辑 | `/storyboard/batch-edit` | 批量修改场景、标签、状态 |

### 5.2 核心功能详情

#### 分镜设计
- **统计卡片（4列）**: 总分镜数、剧本生成、手动创建、AI辅助
- **搜索筛选**: 分镜名称搜索、来源筛选（剧本生成/手动创建/AI辅助）、剧集选择
- **操作按钮**: 新建分镜、剧本生成、AI辅助、提交审核、撤回审核、版本历史
- **可视化面板**: ArtStoryboardPanel组件 — 网格视图（卡片布局）+ 时间线视图（水平比例条）
- **拖拽排序**: VueDraggable支持
- **多选**: Ctrl/Cmd+Click
- **AI辅助生成弹窗**: 生成方式（基于剧本/基于描述）、生成数量(1-20滑块)、描述提示
- **版本历史弹窗**: ElTimeline展示版本列表，支持回退到指定版本
- **状态标签**: 草稿(info)、设计中(primary)、已完成(success)、已归档(warning)
- **来源标签**: 剧本生成(success)、手动创建(primary)、AI辅助(info)

#### 场景编排
- **拖拽列表**: VueDraggable支持场景重排
- **场景信息**: 拖拽手柄、序号徽章、名称、类型标签、元数据（背景/时间/氛围）、包含镜头标签
- **场景类型**: 内景(primary)、外景(success)、虚实结合(warning)、摄影棚(info)
- **批量编辑**: 类型、时间、氛围（全部可清空）
- **相机参数**: 光圈、ISO(100-12800)、色温(2000-10000K)
- **时间选项**: 清晨、上午、中午、下午、黄昏、夜晚
