## 1. 系统管理

**路由前缀**: `/system`
**访问角色**: `platform_admin`（全功能）、`team_admin`（仅用户管理）

### 1.1 管理员仪表盘 (`/system/admin-dashboard`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 平台级全局概览，展示聚合统计数据 |
| **页面元素** | 4个统计卡片（总用户数、总团队数、总项目数、今日AI调用）+ 4个图表占位（用户增长趋势、团队活跃度、存储使用统计、AI服务调用分布） |
| **数据来源** | `fetchGetDashboard()` → `GET /api/statistics/dashboard` |
| **图表状态** | 图表区域目前为占位符，尚未接入 ECharts |

### 1.2 用户管理 (`/system/user`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 管理员用户的增删改查、状态管理 |
| **搜索条件** | 用户名、性别、手机号、邮箱、状态 |
| **列表字段** | 头像+姓名+邮箱（组合渲染）、性别（可排序）、手机号、状态标签、创建日期（可排序） |
| **状态模型** | 在线(1/success)、离线(2/info)、异常(3/warning)、已停用(4/danger) |
| **关键操作** | 新增/编辑（Dialog表单）、删除（实际为停用：`fetchUpdateUserStatus(id, 4)`） |
| **API** | `GET /api/admin/users`、`GET /api/admin/users/{id}`、`PUT /api/admin/users/{id}/status` |
| **Hook** | 使用 `useTable` 统一表格行为 |

### 1.3 角色管理 (`/system/role`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 角色CRUD及菜单权限分配 |
| **搜索条件** | 角色名称、角色编码、描述、启用状态、日期范围 |
| **列表字段** | 角色ID、名称、编码、描述（tooltip）、启用状态标签、创建时间 |
| **关键操作** | 菜单权限分配（`RolePermissionDialog`）、编辑角色（`RoleEditDialog`）、删除角色 |
| **API** | `GET /api/admin/roles`、`POST/PUT/DELETE /api/admin/roles/{id}` |

### 1.4 菜单管理 (`/system/menu`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 树形菜单/路由管理，支持按钮级权限节点 |
| **搜索方式** | 客户端按菜单名和路由地址过滤 |
| **菜单类型** | 目录（有子级）、菜单（有path）、外链（有link）、Iframe（有link+isIframe）、按钮（isAuthButton） |
| **权限控制** | 按钮级权限通过 `v-auth="'add'"` 指令控制；`authList` 条目转为子节点展示 |
| **API** | `GET /api/v3/system/menus/simple`、`POST/PUT/DELETE /api/admin/menus/{id}` |
| **特殊说明** | 菜单列表接口使用 `v3` 前缀，与其他系统接口不一致 |

### 1.5 审计日志 (`/system/audit-logs`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 配置变更审计日志的只读查看器 |
| **搜索条件** | 操作人、操作类型（登录/新增/修改/删除/导出）、日期范围 |
| **列表字段** | 日志ID、操作人、操作类型（标签+颜色）、操作对象、IP地址、操作时间、结果、详情 |
| **详情展示** | Dialog中显示所有字段，JSON详情用 `<pre>` 块展示 |
| **API** | `GET /api/admin/config/audit` |

### 1.6 计费配置 (`/system/billing-config`)

| 维度 | 说明 |
|------|------|
| **核心功能** | AI模型定价配置的CRUD管理 |
| **表单字段** | 模型名称、模型编码、积分价格（2位精度）、单位（按次/按千token/按秒/按张） |
| **状态管理** | 通过 ElSwitch 切换启用/禁用 |
| **API** | `GET/POST/PUT /api/admin/billing`、`PUT /api/admin/billing/{id}/toggle` |

### 1.7 平台团队管理 (`/system/platform-teams`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 平台管理员级别的团队生命周期管理 |
| **搜索条件** | 关键词（团队名/ID）、状态（启用/禁用） |
| **列表字段** | 团队ID、名称、所有者、成员数、项目数、状态（开关）、创建时间 |
| **关键操作** | 创建团队（prompt输入）、查看成员（子表格）、切换状态、删除 |
| **API** | `GET/POST/DELETE /api/admin/teams`、`PUT /api/admin/teams/{id}/status`、`GET /api/admin/teams/{id}/members` |

### 1.8 视频模型配置 (`/system/video-models`)

| 维度 | 说明 |
|------|------|
| **核心功能** | AI视频生成模型的CRUD配置 |
| **表单字段** | 模型名称、编码、提供商、最大时长（秒）、支持比例（多选：16:9/9:16/1:1/4:3） |
| **API** | `GET/POST/PUT/DELETE /api/admin/videos/models` |

### 1.9 Dify工作流配置 (`/system/dify-workflows`)

| 维度 | 说明 |
|------|------|
| **核心功能** | Dify AI工作流集成的CRUD配置，含连接测试 |
| **表单字段** | 工作流编码（编辑时禁用）、名称、API端点、API密钥（密码输入）、超时时间 |
| **特殊功能** | 测试连接按钮（`fetchTestWorkflowConnection`）、API密钥脱敏显示（前4+****+后4） |
| **API** | `GET/POST/PUT/DELETE /api/admin/dify-workflows`、`POST /api/admin/dify-workflows/test-connection` |

### 1.10 运行时配置 (`/system/runtime-config`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 键值对系统配置管理，支持敏感值脱敏和缓存刷新 |
| **敏感检测** | key包含"key"或"secret"时自动标记为敏感 |
| **脱敏规则** | 敏感值显示为 `****` + 最后4位 |
| **特殊功能** | 刷新缓存按钮（`POST /api/admin/config/refresh`） |
| **API** | `GET/POST/PUT/DELETE /api/admin/config`、`GET /api/admin/config/{key}` |

### 1.11 其他系统子页面

| 页面 | 路径 | 功能 |
|------|------|------|
| 团队创建 | `/system/team-create` | 新建团队表单（名称2-50字符、描述200字符内） |
| 团队邀请 | `/system/team-invite` | 通过邮箱/手机号邀请成员并分配角色 |
| 团队权限 | `/system/team-permission` | 开关式权限分配，切换时调用 `fetchSetRolePermissions` |
| 个人中心 | `/system/user-center` | 个人资料编辑+密码修改（密码修改未接入API） |

## 2. 仪表盘

**路由前缀**: `/dashboard`
**访问角色**: 全部四种角色

### 2.1 控制台 (`/dashboard/console`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 工作台首页，组装多个子模块，处理新用户引导 |
| **子模块** | `CardList`（KPI卡片）、`ActiveUser`（活跃用户柱状图）、`SalesOverview`（积分趋势折线图）、`RecentProject`（最近项目表）、`PendingReview`（待审核项）、`LatestNotice`（最新通知） |
| **新用户引导** | 三层检查：(a)无用户名/邮箱→完整引导，(b)无团队→仅邀请码引导，(c)已完成→跳过 |
| **API** | `fetchGetMyTeams()` 检查团队归属 |

### 2.2 CardList 统计卡片

| 指标 | 数据来源 |
|------|---------|
| 待审核数 | `fetchGetDashboard().pendingReviews` |
| 项目进度 | `fetchGetDashboard().projectProgress` |
| 拥有项目 | `fetchGetDashboard().ownedProjects` |
| 积分余额 | `fetchGetDashboard().creditsBalance` |

### 2.3 数据分析子页面

| 页面 | 路径 | 核心功能 |
|------|------|---------|
| 资源用量 | `/dashboard/usage` | KPI卡片（存储/AI积分/带宽）+ 趋势折线图（日/周/月）+ 同比/环比柱状图 |
| 深度分析 | `/dashboard/analysis` | 项目分析表 + 成员工作量横柱图 + 产出效率柱状图 + 成员活跃度排名（奖牌标记Top3） |
| 报表生成 | `/dashboard/report` | 表单配置（类型/日期/维度/格式）+ 预览表 + 成本分析环形图 + API文档块 |
| 数据看板 | `/dashboard/data-dashboard` | 6种图表：KPI卡片、柱状图、折线图、环形图、雷达图、热力图、散点图 |
| AI用量 | `/dashboard/ai-usage` | Token用量分析：KPI卡片 + 趋势折线 + 模型分布环形 + 项目分布柱状 + Token明细表 |
| 成本分析 | `/dashboard/cost` | 积分消耗趋势 + 功能分布环形 + 成本预测柱状 + 成本明细表 |

**数据获取模式**: 统计子页面使用 Vue Query composables（`useStatsDashboard`、`useStatsTrends` 等），具备自动缓存和失效机制。

## 3. 项目管理

**路由前缀**: `/project`
**访问角色**: 全部四种角色

### 3.1 项目列表 (`/project/list`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 双视图模式（卡片网格/表格列表），搜索、状态筛选、排序、批量操作 |
| **视图模式** | 卡片视图（封面图+状态标签+成员数+创建者）、表格视图（复选框+操作按钮） |
| **状态模型** | 草稿(0)、进行中(1)、已完成(2)、已归档(3) |
| **批量操作** | 批量归档、批量恢复、批量删除 |
| **创建项目** | Dialog表单（名称、描述、封面上传） |
| **API (Vue Query)** | `useProjectList`、`useCreateProject`、`useDeleteProject`、`useArchiveProject`、`useRestoreProject`、`useCopyProject` |

### 3.2 项目编辑 (`/project/edit`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 项目详情/编辑页，7个Tab页：概览、剧本、分镜、视频、资产、成员、设置 |
| **概览Tab** | 表单（名称/描述/类型/管理者/状态/进度）+ 统计侧边栏 |
| **设置Tab** | 审核门控开关（分镜/首帧/视频）、JSON配置编辑器、封面上传、危险区域（归档/删除） |
| **保存链** | 更新项目信息 → 更新项目配置(JSON) → 更新审核配置 |
| **API** | Vue Query: `useProjectDetail`、`useProjectConfig`、`useReviewConfig`、`useUpdateProject` 等 |

### 3.3 子页面（隐藏路由）

| 页面 | 路径 | 功能 |
|------|------|------|
| 剧本管理 | `/project/scripts` | 剧本CRUD、状态筛选（草稿/待审/已批/已拒）、文件上传 |
| 角色管理 | `/project/characters` | 角色CRUD、性别筛选、头像上传 |
| 剧集管理 | `/project/episodes` | 剧集+镜头管理，分栏布局，拖拽排序（镜头管理TODO待接入） |
| 成员管理 | `/project/member` | 成员邀请、角色变更、移除（服务端分页+搜索） |
| 项目统计 | `/project/statistics` | 统计卡片（剧集/镜头/成员/时长）+ 进度条 + 资源消耗 + 统计表 |

### 3.4 数据流架构

```
API层 (src/api/project.ts) → Vue Query层 (src/api/queries/project.ts) → 视图层
         ↕ Pinia Store (project.ts + project-data.ts) ↕
```

**双Store模式**: `useProjectStore`（全局项目上下文，sessionStorage持久化）与 `useProjectDataStore`（完整创意数据模型：剧集/分镜/角色/轨道），两者通过 `currentProjectId` 双向同步。

## 4. 剧本管理

**路由前缀**: `/script`
**访问角色**: 全部四种角色

### 4.1 剧本库 (`/script/library`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 剧本列表和CRUD的核心入口 |
| **搜索筛选** | 关键词搜索、状态筛选（草稿/已完成） |
| **关键操作** | 创建（Dialog表单）、上传（.txt/.md，10MB限制）、查看详情、编辑（跳转ScriptWrite）、删除、提交审核、撤回审核 |
| **审核状态** | 1=待审、2=已批、3=已拒、4=已撤回 |
| **数据富化** | 列表加载后并行调用 `fetchGetScriptDetail` 为每条记录补充审核信息 |
| **API** | `GET/POST/PUT/DELETE /api/projects/{projectId}/scripts`、审核提交/撤回接口 |

### 4.2 剧本编写 (`/script/write`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 全屏剧本文本编辑器，支持自动保存 |
| **编辑器** | 等宽字体 textarea，实时字数/行数统计 |
| **自动保存** | 编辑模式下每30秒自动保存（内容变化时触发） |
| **保存状态** | 三态：`unsaved` / `saving` / `saved` |
| **未保存守卫** | 离开页面时弹出确认对话框 |
| **引导流程** | 无scriptId时显示引导Dialog，指向剧本库 |

### 4.3 剧本拆解 (`/script/decompose`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 将剧本拆分为剧集（分段/章节），支持AI自动拆解和手动创建 |
| **布局** | 双面板：左侧剧集列表、右侧详情编辑 |
| **AI拆解** | `fetchDecomposeScript` 触发，可能返回 PROCESSING 状态 |
| **手动操作** | 创建新剧集（名称/序号/内容）、编辑、删除 |

### 4.4 人物小传 (`/script/profiles`)

| 维度 | 说明 |
|------|------|
| **核心功能** | AI生成的角色人物传记展示 |
| **布局** | 双面板：左侧角色列表（可搜索）、右侧详情Tab（基本信息/背景故事/关系网络） |
| **AI生成** | `fetchGenerateCharacterProfiles` 触发，处理 PROCESSING 异步状态 |
| **验证状态** | verified / pending / unverified |

### 4.5 AI审核结果 (`/script/ai-review`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 剧本内容合规审查，展示违规项 |
| **违规类型** | 敏感/政治/色情/暴力/版权/其他 |
| **风险等级** | 高/中/低 |
| **轮询机制** | 5秒间隔轮询 PROCESSING 状态直到 COMPLETED 或 FAILED |
| **统计看板** | 总违规数、高/中/低风险计数 |

### 4.6 创意资产 (`/script/version`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 创意资产管理（角色/服装/场景/道具），提供完整CRUD |
| **资产类型** | character / costume / scene / prop / other |
| **类型特化字段** | 角色：等级/别名；道具：类别/所有者；服装：角色关联/场景关联；场景：场景类型 |
| **AI提取** | `fetchExtractAssets` 从剧本自动提取资产 |
| **参考图上传** | 拖拽上传，图片预览 |

### 4.7 API层 (`src/api/script.ts`)

**30+ 导出函数**，覆盖：
- 剧本CRUD（6个）
- 审核工作流（4个）
- 剧集管理（7个）
- AI内容生成（15+个）：人物小传、资产提取、内容审核、风格配置、参考图分析、语音提示、资产提示、资产图片、视频提示
- AI处理追踪（3个）

## 5. 分镜管理

### 5.1 分镜设计 (`/storyboard/design`)

| 维度 | 说明 |

| **统计** | 总数、剧本生成数、手动数、AI生成数 |

| 维度 | 说明 |

### 5.3 分镜预览 (`/storyboard/preview`)

| **导出功能** | 图片（PNG/JPG/WEBP）、PDF（开发中）、视频（MP4/MOV/AVI，开发中） |

### 5.4 批量编辑 (`/storyboard/batch-edit`)

| 维度 | 说明 |
|------|------|
| **核心功能** | 批量修改多个分镜项的属性 |

| **批量操作** | 批量应用（逐个更新）、批量删除、批量提交审核 |

### 5.5 ArtStoryboardPanel 组件

**路径**: `src/components/core/media/art-storyboard-panel/index.vue`

| 维度 | 说明 |
