## 五、运行时链路

1. 用户登录 → `useUserStore` 缓存 `accessToken`
2. 进入分镜主面板 `/storyboard/design?projectId=xxx`
3. `useStoryboardList(projectId, searchParams)` → `fetchGetStoryboardList` → `GET /api/projects/{projectId}/storyboards`
4. 响应拦截器按 `BaseResponse` 解包出 `data`，`design/index.vue` 通过 `data.records / data.total` 渲染
5. 双击卡片 → `ShotDetailDrawer` 触发 `useStoryboardDetail(id)` → 展示 5 个 Tab
6. 任何 CUD 操作完成后，`vue-query` 自动 invalidate 相关 query 键，列表自动刷新

## 六、剩余风险与建议

1. **后端 BUG**：分镜创建（POST）当前 500，请后端排查；
2. **分镜列表空态**：`data.records = []` 是合规空响应，前端已用 `data.records || []` 与 `data.total ?? list.length` 兼容；
3. **AI 拆解端点**：调用 Dify，耗时长且需要积分，建议前端在 AI 子模块（[ai/index.vue](file:///c:/Users/MicaForever/Desktop/dreamcraftastraneweb-fix-sales-overview-reactivity/src/views/storyboard/ai/index.vue)）中通过 `useAiProcessHistory` 轮询任务状态；
4. **错误信息本地化**：`http/index.ts` 已统一弹出 `message`，后续可加 i18n 兜底。
