# 分镜模块重构设计方案

> **版本**: v2.0
> **适用项目**: Dreamcraft Astrane Web
> **重构目标**: 在现有 `分镜-管理` / `剧本-分镜列表` / `审核-中心` / `图片-生成` / `视频-生成` / `AI-处理记录` API 能力基础上，重新规划分镜模块的产品形态、领域模型、子模块拆分与前后端协作方式。
> **前置依赖**: 已阅读 `docs/API/分镜-管理/api.json`、`docs/API/剧本-分镜列表/api.json`、`docs/API/审核-中心/api.json`、`docs/API/AI-处理记录/api.json`、`docs/API/图片-生成/api.json`、`docs/API/视频-生成/api.json`，并对照 `docs/核对结果/分镜设计方案.md` 与 `docs/核对结果/核对结论_v2.md`。

---

## 一、重构背景与目标

### 1.1 现状（v1 设计遗留问题）
1. **领域边界模糊**：分镜-管理、剧本-分镜列表、剧本-拆解、审核-中心都涉及分镜数据，但页面只把它们当作"分镜表"。
2. **AI 能力未贯通**：分镜拆解 / 重建依赖 `AI-处理记录` 异步轮询，但前端缺乏统一的 AI 任务面板。
3. **资源关联未建模**：分镜 ↔ 配图（main/reference/thumbnail）、分镜 ↔ 资产（character/scene/prop/clothes/audio）、分镜 ↔ 镜头（Scene）、分镜 ↔ 角色之间没有清晰的产品语义。
4. **视图单一**：仅表格 + 故事板两张视图，缺时间线/分幕视图，缺镜头语言（景别/运镜/类型）的可筛选维度。
5. **审核 / 版本 / 批量操作缺位**：后端 13+ 接口未对应前端能力。
6. **后续视频化链路缺位**：分镜→图片→视频→剪辑的链路在产品上没有串联。

### 1.2 重构目标
- **以"分镜"为核心域**，明确其在「项目 → 剧本 → 剧集 → 镜头（Scene）→ 分镜（Shot）→ 配图 → 视频片段」中的位置。
- **拆分为 8 个子模块**，每个子模块职责单一、API 边界清晰、可独立交付。
- **AI 优先**：分镜拆解 / 重建 / 配图生成 / 视频生成全部纳入"AI 任务中心"，提供统一的进度与结果回显。
- **审核与协作**：分镜单条/批量提交、撤回、认领、派发、归档，全部对齐 `审核-中心` 接口。
- **可演进**：为后续"分镜→分幕→剪辑"的过渡保留扩展点。

## 二、领域模型与概念对齐

### 2.1 实体关系

```
Project (项目)
  └─ Script (剧本)
        └─ Episode (分集)
              └─ Scene (镜头 / 场景)        ← 容纳分镜
                    └─ Shot (分镜 / 镜头条目) ← 最小调度单位
                          ├─ ShotImage (配图: main/reference/thumbnail)
                          ├─ ShotAssetLink (资产关联)
                          ├─ ShotCharacterLink (出场角色)
                          ├─ ShotVersion (版本快照)
                          └─ ShotReviewTask (审核任务)
```

### 2.2 关键概念对齐（与现有 API 一一对应）

| 概念 | 业务含义 | 后端资源 | 状态机 |
| --- | --- | --- | --- |
| Shot（分镜） | 单个调度镜头，含画面/运镜/台词/音频 | `ai_storyboard_shots` | 草稿(1) → 待审核(2) → 已通过(3)；待审核可回退为已驳回(4) |
| Scene（镜头） | 分镜的容器，按剧集内 scene_number 排序 | `scenes` | 软删除 |
| ShotImage | 分镜配图 | `storyboard_images` | soft delete，三种类型 |
| ShotAssetLink | 分镜与资产的多对多关联 | `storyboard_assets` | 唯一键(storyboard, asset, assetType) |
| ShotVersion | 版本快照 | `storyboard_versions` | 最多 10 条 |
| ShotReviewTask | 审核任务 | `review_tasks` | 待办/审核中/通过/驳回/已撤回/已归档 |
| AIProcess | 异步 AI 任务 | `ai_process_records` | submitted/processing/completed/failed |

### 2.3 镜头语言枚举（用于筛选/标签）

| 维度 | 枚举值 |
| --- | --- |
| 景别 (cameraAngle) | wide / medium / close / extreme_close / over_shoulder / pov / birds_eye / dutch |
| 运镜 (cameraMovement) | fixed / pan / tilt / dolly / crane / tracking / steadicam / zoom / rack |
| 镜头类型 (shotType) | narrative / breath / climax / transition |
| 配图类型 (imageType) | main / reference / thumbnail |
| 资产类型 (assetType) | character / scene / prop / clothes / audio |
| 状态 (status) | 1 草稿 / 2 待审核 / 3 已通过 / 4 已驳回 |

## 三、分镜模块拆分（8 个子模块）

> **命名规则**：子模块代号 `SBx`（StoryBoard-x），便于代码内引用。

| 代号 | 子模块 | 核心职责 | 主要 API 来源 | 优先级 |
| --- | --- | --- | --- | --- |
| **SB1** | 分镜主面板 | 列表 / 故事板 / 时间线三视图、筛选、批量 | `分镜-管理`、`剧本-分镜列表` | P0 |
| **SB2** | 分镜编辑 | 创建/更新/删除/重排序/拖拽 | `分镜-管理` | P0 |
| **SB3** | 分镜审核 | 提交/撤回/状态查询/批量审核 | `分镜-管理`（submit/withdraw/review-status/batch）+ `审核-中心` | P0 |
| **SB4** | 分镜版本 | 版本历史/版本回滚/差异对比 | `分镜-管理`（versions/rollback） | P1 |
| **SB5** | 分镜配图 | 配图 CRUD、按类型分组、AI 配图 | `分镜-管理`（images）+ `图片-生成` | P0 |
| **SB6** | 分镜资产 | 资产关联 / 解绑 / 角色绑定 | `分镜-管理`（assets）+ `资产-库` | P1 |
| **SB7** | AI 分镜工作台 | AI 拆解、AI 重建、AI 任务中心 | `分镜-管理`（decompose/rebuild）+ `AI-处理记录` | P0 |
| **SB8** | 分镜视频化 | 分镜→视频生成、任务进度、镜头回灌 | `视频-生成`（Seedance）+ `AI-处理记录` | P1 |

子模块之间的依赖关系：

```
SB1 (主面板) ──┬─→ SB2 (编辑)
              ├─→ SB3 (审核)
              ├─→ SB4 (版本)
              ├─→ SB5 (配图)
              ├─→ SB6 (资产)
              ├─→ SB7 (AI 工作台)
              └─→ SB8 (视频化)

SB5 / SB8 ──→ 共用 AI 任务中心（AI-处理记录）
SB3 ──→ 复用 审核-中心 的任务列表
```

## 四、子模块 SB1 — 分镜主面板（P0）

### 4.1 定位
- 整个分镜模块的入口页面，对应 `分镜-管理` 中"列表/详情/镜头列表"三类接口。
- 兼容两种入口：
  - **从剧本分镜进入**：`GET /api/projects/{projectId}/scripts/{scriptId}/storyboards`，按分集分组。
  - **从项目分镜进入**：`GET /api/projects/{projectId}/storyboards`，分页。

### 4.2 路由与布局
- 路由：`/projects/:projectId/storyboards?scriptId=&episodeId=&sceneId=`
- 页面分为四区：工具栏 / 主内容 / 详情抽屉 / 状态栏。

```
┌─────────────────────────────────────────────────────────────┐
│ 顶部 Tab  [分镜总览] [分集视图] [时间线] [AI工作台] [视频化]   │
├─────────────────────────────────────────────────────────────┤
│ 工具栏                                                         │
│ [筛选: 集/场/景别/运镜/类型/状态/来源] [搜索]  [批量▼] [+新建]   │
├─────────────────────────────────────────────────────────────┤
│ 主内容（视图切换）                                              │
│ ┌─ 故事板视图 (默认) ───────────────────────────────────────┐│
│ │ EP01  ▢ SB-001 ▢ SB-002 ▢ SB-003 ▢ SB-004 ▢ SB-005      ││
│ │ EP02  ▢ SB-006 ▢ SB-007 ▢ SB-008 …                          ││
│ └──────────────────────────────────────────────────────────┘│
│ ┌─ 分集视图（按集分组）──────────────────────────────────────┐│
│ │ EP01   [分镜列表 + Scene 折叠]                              ││
│ └──────────────────────────────────────────────────────────┘│
│ ┌─ 时间线视图 ──────────────────────────────────────────────┐│
│ │ 0s    5s    10s   15s   20s   25s   30s   35s                ││
│ │ [■SB1][■SB2][■SB3][■SB4][■SB5][■SB6][■SB7][■SB8]            ││
│ └──────────────────────────────────────────────────────────┘│
├─────────────────────────────────────────────────────────────┤
│ 详情抽屉 (右侧)                                                │
├─────────────────────────────────────────────────────────────┤
│ 状态栏  共 24 个 | 总时长 120s | 草稿 10 / 审核 5 / 通过 9   │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 三视图数据契约

| 视图 | 数据源 | 关键字段 |
| --- | --- | --- |
| 故事板视图 | `listStoryboards` + `getStoryboards` | 配图/标题/景别/运镜/时长/状态 |
| 分集视图 | `getStoryboards`（按 episode 分组） | episodeId/sceneId/shotNo/shotType |
| 时间线视图 | `listStoryboards`（仅 shotType + durationSeconds） | 累积时长、shotType 色带 |

### 4.4 筛选维度（对应后端枚举）
- 分集（episodeId）/ 镜头（sceneId）
- 景别（cameraAngle 多选）
- 运镜（cameraMovement 多选）
- 镜头类型（shotType 多选：narrative/breath/climax/transition）
- 状态（status 多选：1/2/3/4）
- 来源（AI 拆解 / AI 重建 / 人工）
- 关键词（标题/描述/台词模糊匹配）

### 4.5 关键交互
- 多选 + 批量工具栏（→ SB2 / SB3）
- 卡片双击 → 打开详情抽屉（→ SB2 编辑表单）
- 拖拽重排序 → 调用 `PUT /api/scenes/{sceneId}/storyboards/reorder`
- 视图切换状态写入 `localStorage`，刷新保留

### 4.6 必备前端组件
- `StoryboardFilters.vue`
- `StoryboardBoard.vue` / `StoryboardEpisodeGroup.vue` / `StoryboardTimeline.vue`
- `StoryboardCard.vue`（被三视图复用）
- `StoryboardStatusBar.vue`

## 五、子模块 SB2 — 分镜编辑（P0）

### 5.1 定位
- 提供分镜的创建、编辑、删除、复制、批量更新、重排序等"写"操作。
- 同时承载"Scene 自动创建"的兼容逻辑（旧接口 sceneId 缺省时由后端按 episode 自动创建/复用）。

### 5.2 接口映射

| 操作 | 入口 | 接口 | 说明 |
| --- | --- | --- | --- |
| 新建 | 工具栏 [+新建] / 时间线空白处右键 | `POST /api/projects/{projectId}/storyboards` | 必传 `episodeId`，sceneId 可选 |
| 编辑 | 卡片/抽屉"编辑" | `PUT /api/storyboards/{storyboardId}` | 部分字段更新，自动生成版本快照 |
| 删除 | 抽屉/批量 | `DELETE /api/storyboards/{storyboardId}` | 软删除 |
| 批量删除 | 批量工具栏 | `POST /api/storyboards/batch-delete` | ≤100 条，支持 hardDelete |
| 重排序 | 故事板视图拖拽 | `PUT /api/scenes/{sceneId}/storyboards/reorder` | 拖拽结束触发 |
| 复制 | 卡片右键 | **新增**：`POST /api/storyboards/{storyboardId}/duplicate` | 复制到同 scene 末尾 |
| 跨场移动 | 抽屉"移动到…" | **新增**：`PUT /api/storyboards/{storyboardId}/move` body `{ sceneId, newOrder }` | 解决 v1 报告"项目级重排缺失" |

### 5.3 编辑表单字段（与后端 `StoryboardCreateRequest` 对齐）
- 基础：title / description / prompt
- 镜头：cameraAngle / cameraMovement / durationSeconds
- 内容：scriptText（台词/旁白） / soundEffect / backgroundMusic
- 元数据：storyboardNo（序号，自动）/ source（manual / ai-decompose / ai-rebuild）
- 关联：scriptId（可选剧本 ID）

### 5.4 表单 UX 要点
- 分三段：基础信息 / 镜头语言 / 视听内容。
- 「自动从 AI 提示词生成描述」按钮：调用 `POST /api/gpt-image/generations`（后续可替换为内部 LLM 适配器）。
- 保存时调用「版本快照」，故在抽屉"版本"标签内可看到 v1/v2/v3。

### 5.5 必备前端组件
- `ShotEditorDrawer.vue`
- `ShotEditorForm.vue`
- `ScenePicker.vue`（用于跨场移动）
- `BatchActionBar.vue`

## 六、子模块 SB3 — 分镜审核（P0）

### 6.1 定位
- 串联分镜提交审核 / 撤回 / 状态 / 批量审核，对接 `分镜-管理` 与 `审核-中心`。
- 单一分镜的状态字段由 `分镜-管理` 维护；多任务协作由 `审核-中心` 维护。

### 6.2 接口映射

| 场景 | 接口 | 状态变化 |
| --- | --- | --- |
| 单条提交 | `POST /api/storyboards/{id}/submit-review?note=` | 1/4 → 2 |
| 单条撤回 | `POST /api/storyboards/{id}/withdraw-review?reason=` | 2 → 1 |
| 状态查询 | `GET /api/storyboards/{id}/review-status` | 返回 VO 含 reviewTaskId/reviewer/comment |
| 批量提交 | `POST /api/storyboards/batch-submit-review` | ≤100 条 |
| 审核认领 | `POST /api/review/{id}/claim` | 任务进入"审核中" |
| 审核决策 | `POST /api/review/{id}/decide` | 通过/驳回 |
| 审核派发 | `POST /api/review/{id}/dispatch` body `{ assigneeId }` | 派给指定审核人 |
| 审核归档 | `POST /api/review/{id}/archive` | 任务结束 |
| 驳回原因配置 | 项目级 `GET/PUT /api/review/projects/{projectId}/route-config` | 驳回到指定组 |

### 6.3 状态机与按钮显隐

| 当前状态 | 可用操作 |
| --- | --- |
| 1 草稿 | 提交审核、编辑、删除 |
| 2 待审核 | 撤回审核、查看审核任务 |
| 3 已通过 | 查看详情、复制为新分镜 |
| 4 已驳回 | 重新提交、编辑、删除（带驳回原因高亮） |

### 6.4 抽屉中的"审核"Tab
- 当前状态 + 审核任务 ID
- 审核人头像 / 审核时间 / 审核意见（Markdown）
- 驳回原因（从 `route-config` 中匹配标签）
- 快捷按钮：认领 / 通过 / 驳回（打开驳回原因选择器）/ 派发

### 6.5 审核中心侧入口
- 审核中心页（`/review-center`）复用 `分镜-管理` 抽屉作为详情侧栏；分镜审核任务与剧本/图片/视频任务统一在中心展示。

## 七、子模块 SB4 — 分镜版本（P1）

### 7.1 定位
- 解决"误改找不回"与"对比修改"两类诉求。
- 对应接口：`GET /api/storyboards/{id}/versions`、`POST /api/storyboards/{id}/versions/{vid}/rollback`。

### 7.2 UI
- 抽屉内的"版本"Tab，列出最近 10 条版本。
- 列表项：版本号 / 修改时间 / 修改人 / 修改摘要 / 差异按钮 / 回滚按钮。
- 回滚前自动创建当前快照，回滚后弹 toast 告知"已生成 vN+1"。

### 7.3 差异对比
- 选用 monaco-diff 或 jsdiff 做字段级 diff。
- 字段映射：title / description / prompt / cameraAngle / cameraMovement / durationSeconds / scriptText / soundEffect / backgroundMusic。
- 视图：左右双栏 diff，红/绿高亮。

### 7.4 注意事项
- 配图、资产关联不计入"版本快照"（与后端现状一致：仅字段级快照）；如需关联级快照，需后端补 schema 字段 `versionScope`。
- 批量回滚不在第一期。

## 八、子模块 SB5 — 分镜配图（P0）

### 8.1 定位
- 分镜配图的三种类型管理：`main`（主图）、`reference`（参考图）、`thumbnail`（缩略图）。
- 同时承担"AI 一键配图"能力（`图片-生成`）。

### 8.2 接口映射

| 操作 | 接口 |
| --- | --- |
| 列表 | `GET /api/storyboards/{id}/images` |
| 添加 | `POST /api/storyboards/{id}/images?imageUrl=&imageType=main` |
| 删除 | `DELETE /api/storyboards/images/{imageId}` |
| AI 配图 | `POST /api/gpt-image/generations`（提交） + `GET /api/gpt-image/tasks/{taskId}`（轮询） |
| 设为主图 | `PUT /api/storyboards/images/{imageId}/set-main` （**新增**） |

### 8.3 UI
- 抽屉"配图"Tab，三段：主图区 / 参考图网格 / 缩略图。
- 主图大图展示 + 「重新生成」按钮（→ AI 配图弹窗）。
- 参考图：拖拽排序、批量删除、点击预览大图。
- 「AI 配图」弹窗：选择 prompt（默认取分镜 `prompt` 字段）、尺寸、分辨率、质量、参考图；提交后写入 AI 任务中心；完成回调直接写入参考图列表。

### 8.4 主图唯一性
- 当前后端 `imageType` 是普通字段，理论上一个分镜可有多个 `main`，产品侧需要 UI 约束"主图只能一张"。
- 解决：增加 "set-main" 接口；或在前端做"设为主图时把其他 main 降级为 reference"。

## 九、子模块 SB6 — 分镜资产（P1）

### 9.1 定位
- 关联资产库中的 character / scene / prop / clothes / audio 到分镜。
- 用于"分镜→资产一致性"管理（出镜角色必须存在于资产库）。

### 9.2 接口映射

| 操作 | 接口 |
| --- | --- |
| 列表 | `GET /api/storyboards/{id}/assets` |
| 关联 | `POST /api/storyboards/{id}/assets?assetId=&assetType=character` |
| 解绑 | `DELETE /api/storyboards/{storyboardId}/assets/{assetId}` |
| 角色出镜 | 复用 character 资产类型，无独立接口 |
| 从资产库选择 | 弹资产库 `AssetPicker.vue`，按 type 过滤 |

### 9.3 抽屉"资产"Tab
- 分组展示：角色 / 场景 / 道具 / 服装 / 音频。
- 每组内为可拖拽 chips，点击可预览资产详情。
- "从资产库添加"按钮 → 资产抽屉（复用 `资产-库`）。

### 9.4 校验与提示
- 若某分镜引用了"未审核通过"的资产（与"提示词-审核"联动），需要展示风险提示。
- 若分镜审核通过后修改了资产关联，触发"需重新提交审核"提示。

## 十、子模块 SB7 — AI 分镜工作台（P0）

### 10.1 定位
- AI 拆解 / 重建的统一入口，统一 AI 任务进度与结果回显。
- 调用 `分镜-管理` 中的 `decomposeStoryboard` / `rebuildStoryboard`，进度查询走 `AI-处理记录`。

### 10.2 接口映射

| 操作 | 接口 | 类型 |
| --- | --- | --- |
| AI 拆解 | `POST /api/projects/{pid}/scripts/{sid}/episodes/{eid}/storyboard/decompose` | 异步 |
| AI 重建 | `POST /api/projects/{pid}/scripts/{sid}/episodes/{eid}/storyboard/rebuild` body `{modifyInstructions, force}` | 异步 |
| 任务状态 | `GET /api/ai-process/status?type=storyboard_decompose&businessId={episodeId}` | 轮询 |
| 任务历史 | `GET /api/ai-process/history?type=storyboard_decompose&businessId=...` | 拉取 |
| 历史详情 | `GET /api/ai-process/history/{id}` | 查看 |

### 10.3 拆解弹窗
- 字段：剧本（下拉）/ 分集（下拉，依赖剧本加载）/ 风格配置（可选 `styleConfigId`）/ 强制重处理（`force`）。
- 提交后弹"AI 任务中心"抽屉，实时显示阶段：submitted → processing → completed。
- 完成后给出摘要：生成 N 个分镜 / 预计总时长 / Token 消耗 / 积分扣减。

### 10.4 重建弹窗
- 字段：剧本 / 分集 / 修改说明（多行）/ force。
- 行为：先调用 `getStoryboards` 取当前数据作为 AI 输入；超过 30% 改动 → 全量重建，否则局部重建。
- AI 补写的镜头带 `[AI补写]` 标记，P0 修正自动记录。

### 10.5 AI 任务中心（跨子模块复用）
- 顶部导航"AI 任务中心"图标，红点提示未完成任务。
- 任务列表（按业务类型分组）：`storyboard_decompose` / `storyboard_rebuild` / `image_generation` / `video_generation`。
- 列表项：业务名、状态、进度条、积分消耗、开始/结束时间、结果跳转。
- 完成后可一键跳转到对应分镜/图片/视频。

### 10.6 速率与积分
- 提交前调用 `积分-用量` 查询余额，余额不足时禁用提交按钮并提示。
- 提交后从任务结果中拿到 `cost`，写入"我的用量"统计。

## 十一、子模块 SB8 — 分镜视频化（P1）

### 11.1 定位
- 在分镜审核通过后，串联"分镜 → 视频"：使用 `视频-生成`（Seedance 2.0）把每个分镜转化为视频片段。
- 为后续「剪辑-管理」提供原始视频素材。

### 11.2 接口映射

| 操作 | 接口 |
| --- | --- |
| 提交生视频 | `POST /api/seedance/generations` body `{prompt, images, model, duration, ratio, ...}` |
| 任务状态 | `GET /api/seedance/tasks/{taskId}` |
| 取消任务 | `POST /api/seedance/tasks/{taskId}/cancel` |
| 提示词违规检测 | `POST /api/video/check-prompt`（如存在） |
| 回灌到分镜 | `PUT /api/storyboards/{id}/video-clip`（**新增**） |

### 11.3 工作流
```
分镜（已通过）
   ↓
"生视频"按钮 → 选择 prompt 模板（默认取分镜 prompt + 配图作 first_frame）
   ↓
调用 Seedance → 返回 taskId → 写入 AI 任务中心
   ↓
轮询 / 回调完成 → 拿到视频 URL
   ↓
回灌到分镜.videoClipUrl / .videoTaskId
   ↓
剪辑模块可按分镜 ID 拉取视频片段
```

### 11.4 抽屉"视频"Tab
- 当前视频片段播放器（如已完成）+ 任务进度（如生成中）。
- 状态：未生成 / 排队中 / 生成中 / 已完成 / 失败。
- 操作：重新生成 / 取消 / 下载 / 替换 prompt。

### 11.5 提示词工程
- 模板：`{分镜 prompt} + {风格配置} + {运镜} + {景别}`，长度受 `Seedance` 限制（按接口规范做截断）。
- 提供"优化提示词"按钮（→ `fetchOptimizePrompt`，如未提供则前端本地模板化）。

## 十二、跨子模块通用设计

### 12.1 路由表

| 路由 | 组件 | 说明 |
| --- | --- | --- |
| `/projects/:projectId/storyboards` | `StoryboardMainView` | SB1 主面板 |
| `/projects/:projectId/storyboards/:shotId` | 同上 + 默认打开抽屉 | 直接进入分镜 |
| `/projects/:projectId/scripts/:scriptId/storyboards` | 同上 + `scriptId` 入参 | 剧本分镜入口 |
| `/projects/:projectId/storyboards/ai` | `StoryboardAiWorkbench` | SB7 工作台 |
| `/projects/:projectId/storyboards/:shotId/video` | `StoryboardVideoPanel` | SB8 |
| `/ai-tasks` | `AiTaskCenter` | 跨子模块 AI 任务 |
| `/review-center` | `ReviewCenter` | 复用审核中心 |

### 12.2 Pinia Store 划分

```
stores/
  storyboard/
    index.ts        # 主数据（list/filter/viewMode/selectedIds）
    detail.ts       # 当前打开分镜的详情
    images.ts       # 配图
    assets.ts       # 资产
    versions.ts     # 版本
    review.ts       # 审核任务
    ai.ts           # AI 任务
    video.ts        # 视频化
```

### 12.3 权限模型
- 写操作（创建/编辑/删除/重排序/配图）：需要项目 `WRITE` 权限。
- 审核操作（提交/撤回/通过/驳回）：需要项目 `REVIEW` 权限。
- AI 操作（拆解/重建/生图/生视频）：需要项目 `WRITE` + 积分余额 > 0。
- 视频化：分镜状态必须为"已通过(3)"，否则按钮 disabled + tooltip 提示。

### 12.4 错误与降级
- 后端接口 5xx：toast + 保留本地修改（IndexedDB 草稿）。
- AI 任务失败：任务中心展示失败原因，支持"重试"按钮（重新调用原接口）。
- 审核驳回：抽屉顶部红条展示驳回原因（来自 `route-config`）。

### 12.5 性能与体验
- 故事板视图虚拟滚动（≥200 条分镜时启用 `vue-virtual-scroller`）。
- 时间线视图使用 SVG 绘制色带，避免大量 DOM。
- 详情抽屉懒加载：打开时才请求 versions / images / assets。
- 配图 / 视频使用懒加载 + 占位图。

## 十三、与现有 API 的差异 / 待补接口

> 本节列出为落地本方案 **必须** 让后端新增/调整的接口，优先级标注。

| 接口 | 状态 | 优先级 | 说明 |
| --- | --- | --- | --- |
| `POST /api/storyboards/{id}/duplicate` | 新增 | P1 | 复制分镜到同 scene 末尾 |
| `PUT /api/storyboards/{id}/move` body `{sceneId, newOrder}` | 新增 | P0 | 跨场移动 |
| `PUT /api/storyboards/images/{imageId}/set-main` | 新增 | P1 | 强制唯一主图 |
| `PUT /api/storyboards/{id}/video-clip` body `{taskId, videoUrl, durationSeconds}` | 新增 | P1 | 视频片段回灌 |
| `GET /api/projects/{pid}/storyboards/grouped` | 新增 | P1 | 主面板"按集分组"专用接口（避免前端拼装 N 次请求） |
| `POST /api/storyboards/batch-update` body `{ids, fields:{...}}` | 新增 | P2 | 批量改景别/运镜 |
| `GET /api/storyboards/{id}/diff?from=v1&to=v2` | 新增 | P2 | 版本字段 diff（前端也可基于 list 自行 diff） |
| `POST /api/ai-process/retry` body `{recordId}` | 新增 | P2 | 任务失败重试（也可让前端直接重调原接口） |
| `POST /api/video/check-prompt` | 确认 | P1 | 校验视频提示词是否合规 |

如后端暂时无法提供，本方案支持以下降级：
- duplicate / move：用现有 create + delete + reorder 组合实现。
- grouped：前端在拿到 `getStoryboards` 后自行按 episodeId 聚合。
- set-main：前端 local state 约束主图唯一，保存时一并带上去。
- video-clip：先在前端抽屉用 `localStorage` 暂存，等后端提供后再回灌。
